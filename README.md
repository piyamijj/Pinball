# Karanlık Konak – Gotik Pinball
Özgün gotik konak temalı pinball (Vite + Matter.js, Canvas2D, WebAudio).
- Geliştirme: `npm install && npm run dev`
- Derleme: `npm run build` (çıktı: `dist`)
- Android: `npm run build && npx cap add android && npx cap sync android` (CI APK'yı otomatik derler)
- Kuponlar menüde/duraklatmada girilir; sadece SHA-256 özetleri kodda tutulur.
